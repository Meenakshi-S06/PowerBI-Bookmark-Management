# Bookmark-Based Management Report

## Project Overview

A Power BI management dashboard that allows users to switch between Sales, Quantity, and Profit views using bookmarks and navigation buttons.

## Features

- Sales analysis
- Quantity analysis
- Profit analysis
- Interactive bookmark navigation
- Sales by Region
- Sales by Category
- Quantity by Region
- Quantity by Category
- Profit by Region
- Profit by Category

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- SQL Server
- Superstore Dataset

## Dashboard Views

### Sales View
Displays sales performance by region and category.

### Quantity View
Displays quantity performance by region and category.

### Profit View
Displays profit performance by region and category.

## Power BI Concepts Used

- Power Query
- Data Transformation
- DAX Measures
- Cards
- Bar Charts
- Column Charts
- Bookmarks
- Bookmark Navigator
- Interactive Report Navigation
